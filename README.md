# Logistics Data Analysis and Visualization

## YUVA Internship — Week 3 Project

This project demonstrates analysis of a hypothetical logistics dataset using Python.

### Files
- `week3_logistics_dataset.csv` — 300 hypothetical shipment records
- `week3_logistics_analysis.py` — Python code for summary metrics and charts
- `YUVA_Week3_Logistics_Analysis_Report.docx` — detailed Word report
- `week3_chart_delivery_mode.png` — average delivery time by transport mode
- `week3_chart_cost_mode.png` — average shipping cost by transport mode
- `week3_chart_ontime_region.png` — on-time delivery rate by region
- `week3_chart_delay_satisfaction.png` — delay versus customer satisfaction

### Tools
Python, Pandas, NumPy, Matplotlib, Microsoft Word.

### How to run
1. Install Python.
2. Install dependencies: `pip install pandas numpy matplotlib`
3. Keep the CSV and Python script in the same folder.
4. Run: `python week3_logistics_analysis.py`

### Important note
The dataset is synthetic/hypothetical and created for educational purposes. Results are not real company performance data.
